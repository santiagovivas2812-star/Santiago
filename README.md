# Santiago

## ¿Cómo eliminar un repositorio en GitHub?

Sigue estos pasos para eliminar un repositorio en GitHub:

1. **Inicia sesión** en tu cuenta de GitHub en [https://github.com](https://github.com).

2. **Navega al repositorio** que deseas eliminar.

3. Haz clic en la pestaña **Settings** (Configuración) dentro del repositorio.

4. Desplázate hasta la sección **Danger Zone** (Zona de peligro) al final de la página.

5. Haz clic en **Delete this repository** (Eliminar este repositorio).

6. GitHub te pedirá que **confirmes** la acción escribiendo el nombre completo del repositorio (por ejemplo, `usuario/nombre-repositorio`).

7. Haz clic en **I understand the consequences, delete this repository** (Entiendo las consecuencias, eliminar este repositorio).

> ⚠️ **Advertencia:** Esta acción es **irreversible**. Una vez eliminado el repositorio, no podrás recuperar el código, los issues, los pull requests ni ningún otro dato asociado.

### Requisitos

- Debes ser el **propietario** del repositorio o tener permisos de administrador para poder eliminarlo.
- Si el repositorio pertenece a una organización, es posible que necesites permisos adicionales de la organización.
